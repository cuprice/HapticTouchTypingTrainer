# Haptic Touch Typing Trainer

## SMD版 製作ガイド

このページでは、Haptic Touch Typing TrainerのSMD版基板を製作し、RP2040-ZEROにプログラムを書き込んで動作させるまでの手順を説明します。

このプロジェクトは、プログラミングや電子工作を学びながら製作したタッチタイピング練習機です。

SMD版では、JLCPCBの基板製造・部品実装サービスを利用することで、対応する表面実装部品（SMD部品）を実装済みの状態で入手できます。

> **注意**
>
> このプロジェクトは完成品として販売されている製品ではありません。
> 個人が電子工作とプログラミングを学びながら製作したプロトタイプです。製作方法や動作について保証するものではありません。
>
> 電子工作やはんだ付けに慣れていない場合は、十分注意して製作してください。
>
> また、製造データや部品表は更新される場合があります。製作前に、使用するバージョンを確認してください。

# 1. この装置について

Haptic Touch Typing Trainerは、**振動と音を使って、次に押すキーを知らせるタッチタイピング練習機**です。

通常のタイピング練習では画面を見ながらキーの位置を覚えますが、この装置では振動を利用することで、手元を見ずにキーの位置を覚えることを目指しています。

30個のキーを10列×3段に配置しています。

8個のキーには振動モーターを搭載しています。

また、キーの段によってブザーの鳴り方を変えることで、次に押すキーがどの段にあるのかを音でも確認できます。

本ガイドでは、最新のSMD版基板の製作方法を説明します。

# 2. 必要なもの

## 基板

SMD版の基板製造には、リポジトリにある以下のデータを使用します。

- Gerberデータ
- 部品表（BOM）
- 部品配置データ（CPL）

PCBの製造とSMD部品の実装には、JLCPCBのサービスを利用できます。

## その他の必要なもの

- RP2040-ZERO
- Cherry MX互換キースイッチ
- Cherry MX対応キーキャップ
- 振動モーター
- USBケーブル
- 必要に応じて、はんだごて、はんだ、ニッパーなどの工具

※ 部品によっては、JLCPCBでの実装対象外となり、別途購入や手作業での取り付けが必要です。

詳細は「3. 電子部品」を参照してください。

## 3.1 JLCPCBで実装する部品

SMD版では、対応する表面実装部品、一部インサート部品をJLCPCBに実装してもらうことを想定しています。

対象となる部品は、JLCPCB向けのBOMとCPLを確認してください。

## 3.2 手作業で取り付ける部品

以下の部品は、基板の設計や注文内容によって、別途取り付けが必要になる場合があります。

- キースイッチ、キーキャップ
- 振動モーター

**注文前に、JLCPCBで実装する部品と、自分で取り付ける部品を必ず確認してください。**

# 4. PCBを製造・実装する

## 4.1 製造データを準備する

リポジトリから最新のSMD版の製造データを入手します。

使用するGerberファイル：

`TYPING-TRAINER-V6.zip`

製造前に、次のファイルがそろっていることを確認します。

- Gerberデータ
- BOMファイル `TYPING-TRAINER-V6-SMD.csv`
- CPLファイル `TYPING-TRAINER-V6-all-pos.csv`

BOMは実装する部品の一覧、CPLは部品の基板上の配置位置や向きを示すデータです。

## 4.2 JLCPCBでPCBを注文する

1. JLCPCBのWebサイトを開きます。
2. Gerberデータをアップロードします。
3. 基板の仕様を確認します。
4. SMD実装サービスを選択します。
5. 実装する面を指定します。
6. BOMファイルをアップロードします。
7. CPLファイルをアップロードします。
8. 部品の割り当てと配置を確認します。
9. 基板のプレビューで、部品の位置や向きに問題がないことを確認します。
10. 見積もりと注文内容を確認し、発注します。

実際の注文画面やサービスの仕様は、注文時のJLCPCBの案内に従ってください。

## 4.3 注文前の確認事項

発注する前に、次の項目を確認してください。

- [ ] 必要な部品がJLCPCBで入手可能
- [ ] 部品のパッケージと基板のフットプリントが一致している
- [ ] 部品の向きと配置が正しい
- [ ] 実装されない部品を把握している

特に、部品の向きや配置に誤りがないか、発注前に十分確認してください。

## 4.4 基板が届いたら

基板が届いたら、次の点を確認します。

- 基板に破損がないこと
- 部品が正しく実装されていること
- 部品の向きに問題がないこと
- はんだ付けに異常がないこと
- 未実装部品が明確になっていること

問題がある場合は、電源を接続する前に原因を確認してください。

# 5. 部品を取り付ける

JLCPCBで実装済みの基板が届いたら、残りの部品を取り付けます。

実際の作業内容は、実装を依頼した部品によって異なります。

半田付けで取り付ける部品：

RP2040-ZERO

手作業で取り付ける部品：

1. キースイッチ
2. キーキャップ
3. 振動モーター

※ この順番は参考例です。実際の基板の構造や部品の実装面に合わせて調整してください。

# 8. RP2040-ZEROを取り付ける

RP2040-ZEROを基板に取り付けます。

RP2040-ZERO本体とピンヘッダーを使い、直接はんだ付けする構成になっています

RP2040-ZEROの向きを間違えないように注意してください。

# 9. 振動モーターを取り付ける

このプロジェクトでは、8個のキーに振動モーターを使用します。

モーターの取り付けには、基板上のモーター接続用ターミナルブロックを使用します。

1. モーターの配線を用意します。
2. 基板の指定位置に配線を通します。
3. ターミナルブロックに配線を接続します。
4. モーターを対応するキーキャップに取り付けます。
5. 配線が外れないことを確認します。

配線が短絡したり、可動部分に挟まったりしないよう注意してください。

# 10. 配線を確認する

電源を入れる前に、以下を確認してください。

- ダイオードの向き
- LEDの向き
- RP2040-ZEROの向き
- MCP23017の向き
- キースイッチソケットのはんだ付け
- モーター配線
- ターミナルブロックの接続
- 電源とGNDが短絡していないこと
- はんだブリッジがないこと
- 部品が正しい位置に取り付けられていること

特に、電源周辺に短絡がないことを確認してからUSBを接続してください。

# 11. RP2040-ZEROをPCに接続する

RP2040-ZEROとPCをUSBケーブルで接続します。

Arduino IDEを使用し、対応するRP2040-ZEROを選択します。

PCでRP2040-ZEROが認識されることを確認してください。

# 12. プログラムを書き込む

リポジトリにあるArduinoスケッチを使用します。

`TrainerV6_rp2040zero4typeBasic/`

使用するスケッチをArduino IDEで開き、RP2040-ZEROに書き込みます。

※ 各スケッチの機能や対応する基板バージョンを確認してから使用してください。

# 13. 動作確認

プログラムを書き込んだら、キーを押して動作を確認します。

この装置では、次に押すキーを振動とブザーによって知らせます。

ブザーはキーの段によって、次のように鳴ります。

- 上段：3回
- 中段：2回
- 下段：1回

振動モーターが付いていないキーについても、振動時間を変えることで位置を知らせる仕組みになっています。

実際の動作は、使用するファームウェアのバージョンによって異なる場合があります。

次の項目を確認してください。

- キー入力が認識される
- ブザーが正しく鳴る
- 振動モーターが正しく動作する
- キーの段に応じた案内が行われる
- 複数のキーを操作しても問題がない

# 14. タイピング練習をする

基本的な使い方は、次のとおりです。

1. 装置をPCなどに接続する
2. 指をホームポジションに置く
3. 振動と音で次のキーを確認する
4. 手元をできるだけ見ずにキーを押す

繰り返し練習することで、キーの位置を覚えることを目指します。

# 15. キーを押す順番を変更する

このプロジェクトでは、タイピング練習で使用するキーの順番をArduinoスケッチから変更できます。

自分の練習方法に合わせて、キーの順番や練習内容を変更できます。

# 16. 3Dプリント部品

リポジトリには、3Dプリンター用のデータも含まれています。

`keycap.stl`

これは、振動モーターを取り付けるための穴があるキーキャップです。

必要に応じて3Dプリンターで出力してください。

3Dプリンターが利用できない場合は、通常のキーキャップを使用し、モーターを両面テープなどで固定する方法もあります。

ただし、モーターが外れたり、配線に負荷がかかったりしないよう注意してください。

# 17. トラブルシューティング

## キーを押しても反応しない

以下を確認してください。

- キースイッチが正しく取り付けられているか
- キースイッチソケットのはんだ付けに問題がないか
- ダイオードの向きが正しいか
- Arduinoのプログラムが正しく書き込まれているか
- RP2040-ZEROとPCが正しく接続されているか

## 振動モーターが動かない

以下を確認してください。

- モーターの配線
- ターミナルブロックの接続
- モーターの取り付け位置
- はんだ付け
- ファームウェアの設定

## ブザーが鳴らない

以下を確認してください。

- ブザーの種類
- ブザーの接続
- はんだ付け
- Arduinoスケッチ
- RP2040-ZEROとの接続

## RP2040-ZEROが認識されない

- USBケーブルを確認する
- Arduino IDEのボード設定を確認する
- COMポートを確認する
- RP2040-ZEROが正しく接続されているか確認する

## SMD部品に問題がある

以下を確認してください。

- 部品が正しい位置に実装されているか
- 部品の向きが正しいか
- はんだブリッジがないか

SMD部品の修正には、適切な工具と作業経験が必要になる場合があります。
